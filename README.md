# カニ・クリーム・コロッケ 素材調整ツール v12

現在のゲーム本体 **v0.9.7** を基準にした編集用セットです。

## v12 のポイント
- 現在ゲームで実際に使っている `dishgen` 素材をそのまま同梱
- 第1工程の現在実装素材を全て同梱
- 第2工程の現在実装素材を全て同梱
- 以前ゲームへ反映した料理レイアウト・左右反転・装飾位置・差し替え素材を `current-project.js` から初期読込
- 既に直した昆布・長靴なども「現在ゲーム版」が初期素材
- ダメな素材だけ切り抜いて同じ素材IDへ置き換えればOK

## 使い方
1. `index.html` を開く
2. 「素材差し替え」タブへ
3. 左の一覧から直したい素材を選ぶ
   - 完成料理パーツ
   - 第1工程
   - 第2工程
   が同じ一覧にあります
4. 原本シートから切り抜く、または自分の画像を追加ソースとして読み込む
5. 「この素材IDを置き換える」
6. 最後に「差し替え素材を書き出し」
7. `kani-asset-pack-v3.json` を ChatGPT に送る

`kani-asset-pack-v3.json` にはゲーム内の実ファイルパス対応表も入るので、そのままゲーム本体へ反映できます。
