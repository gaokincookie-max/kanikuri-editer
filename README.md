# カニ・クリーム・コロッケ 組み合わせプレビュー＆調整ツール v6

## 今回の核心
- 素材差し替えは「素材IDそのもの」を置き換える方式
- キャンバスでレイヤーを動かすと、その役割の基準テンプレート座標も同時に更新
- 具材や液体を切り替えても、座標を再設定しなくてよい
- 完成予想図に近づけるため、「奥の丸ごとコロッケ」と「手前の断面」を別スロット化

## 操作のおすすめ
1. 素材差し替えタブで、土台や断面フレームの切り抜きを先に直す
2. カニ＋クリームを基準料理にする
3. キャンバス上で皿・奥の本体・断面・液体・具材を直接動かす
4. その移動は自動的に基準テンプレートへ反映される
5. 良ければテンプレ保存
6. 他の具材・液体に切り替えて確認

`🔗` がついているレイヤーは基準テンプレートと連動しています。
