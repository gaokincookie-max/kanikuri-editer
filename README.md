# カニ・クリーム・コロッケ 組み合わせプレビュー＆調整ツール v5

一部の素材の切り抜きがうまくいかなかった場合に備えて、
**もとの大きい画像から好きに切り抜いて、そのまま素材ライブラリへ登録できる** 版です。

## 追加点
- 「切り抜き・素材登録」タブを追加
- built-in の大きい素材シートだけでなく、任意の画像ファイルも読み込み可能
- 切り抜き結果を
  - PNG保存
  - 素材ライブラリへ登録
  - 登録して選択中レイヤーへ即適用
  が可能
- JSON保存 / 読込 / テンプレ保存に、カスタム素材も含まれます

## 使い方
1. 料理プレビューで直したいレイヤー（具材や液体など）を選ぶ
2. 切り抜き・素材登録タブへ移動
3. 元画像から自由に切り抜く
4. 「登録して選択中レイヤーへ適用」を押す
5. 必要なら料理プレビューで位置やサイズを微調整する
