# カニ・クリーム・コロッケ アセット調整ツール

`index.html` をブラウザで開くだけで動きます。GitHub Pages / Netlify Drop でも使用できます。

## できること
- 内蔵スプライトシート3枚を読み込み
- 透過領域から素材候補を自動分割
- 矩形 / 多角形 / フリーハンドで自由切り抜き
- 任意画像をアップロードして切り抜き
- 切り抜いた素材を料理プレビューへ直接登録
- レイヤーごとの位置・拡大率・回転・透明度・左右反転・重なり順調整
- 複数パターンの保存と再呼び出し
- 完成プレビューPNGの出力
- プロジェクトJSONの保存 / 復元
- ゲーム挿入用ZIP (`dish_assets.json` + `assets/*.png`) の出力

## ゲーム側へ入れるデータ
「ゲーム用ZIP」を押すと以下を出力します。

- `dish_assets.json`
- `assets/*.png`
- `README.txt`

`dish_assets.json` の `recipes` に、保存した各パターンのレイヤー配置が入ります。
レイヤーは `assetId / x / y / scale / rot / opacity / flip` を保持します。

## 推奨ワークフロー
1. 「切り抜き」で素材を分割
2. 「素材として登録」
3. 「料理プレビュー」で素材をクリックしてレイヤー追加
4. 位置・サイズ・角度を手動調整
5. パターン名をつけて保存
6. 「ゲーム用ZIP」で出力
