# カニ・クリーム・コロッケ 組み合わせプレビュー＆調整ツール v2

最新版の斜め断面アセットを取り込んだ、料理見た目の確認・調整用ツールです。

## できること
- 液体×具材の組み合わせを全パターン一覧で確認
- 現在の原案配置を自動生成
- 各レイヤーをドラッグで位置調整
- マスク位置を調整して、断面からのはみ出しを修正
- PNG保存 / JSON保存・JSON読込
- 補助機能として、素材シートからの自由切り抜き

## ファイル構成
- `index.html`
- `assets/croquette_sheet.png`
- `assets/fill_sheet.png`

そのままGitHub Pagesやローカルで開いて使えます。
