# カニ・クリーム・コロッケ 素材調整ツール v11

## 今回の追加点
- 通常素材・装飾素材のどちらも、同じ素材IDのまま差し替え可能
- 原本シートを `source/` に同梱
- 旧版/別版シートも同梱したので、切り抜きやすい原本を選んで修正可能

## 使い方
1. `index.html` を開く
2. 「素材差し替え」タブを開く
3. 左で修正したい素材IDを選ぶ
4. 中央で原本シートを選んで切り抜く
5. 「この素材IDを置き換える」で反映
6. 「差し替え素材を書き出し」で JSON を保存
7. 保存した JSON を ChatGPT に渡す

## 同梱した原本シート
- 原本A: コロッケ素材シート
- 原本B: 具材素材シート
- 補助A/B: 別版シート
- 旧版: 以前のシート

必要なら、このツールで修正した JSON をもとにゲーム側へ反映します。
