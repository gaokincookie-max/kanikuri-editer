# カニ・クリーム・コロッケ 料理アセット調整ツール

## 主機能
- 料理のレイヤー合成プレビュー
- こちらで用意した原案プリセット（カニ＋クリーム、カニカマ＋マヨ、昆布＋謎液体、焦げ、DJ、逃げる）
- レイヤーごとの位置・拡大率・回転・透明度・左右反転・描画順調整
- 液体・具を断面内部へ収めるための楕円マスク調整
- 合成結果PNGの書き出し
- ゲーム実装用JSONの書き出し／再読込

## 補助機能：切り抜き
- 矩形切り抜き
- 多角形切り抜き
- 自由なぞり切り抜き
- 透過PNG保存
- 切り抜いた画像をその場で素材ライブラリへ追加

## ゲーム連携
JSONは `kani-dish-layout-v1` 形式です。各レイヤーに以下を保存します。
- assetId
- x / y
- scale
- rotation
- alpha
- flipX
- clipInside
- 描画順（layers配列順）

断面マスク（x, y, rx, ry）も同時に保存されます。

## 起動
`index.html` をブラウザで開いてください。GitHub Pages / Netlify Dropでも動作する構成です。
