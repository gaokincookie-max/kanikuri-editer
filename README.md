# カニ・クリーム・コロッケ 料理アセット調整ツール v7

v6をベースに、複数テンプレートと追加レイヤーの保存を強化した版です。

## v7の主な変更

- テンプレートを複数保存できる「テンプレートライブラリ」
- v6 / v7 のJSONを複数選択して一括読込可能
- 「ゲーム取り込み用に全部書き出し」で、全テンプレート・素材差し替え・追加レイヤーを1ファイルに統合
- 複製した湯気などは `semanticRole` を保持
  - 例: 湯気を複製 → `semanticRole: "steam"`
- 複製レイヤーの位置・拡大率・回転・表示順もテンプレートごとに保存
- v6のローカル保存テンプレートが残っていれば自動移行を試みる

## ゲームへ渡すファイル

ツールの「ゲーム取り込み用に全部書き出し」を押すと、
`kani-dish-game-project-v7.json` が出力されます。

このファイルには次が入ります。

- `templates[]` : 複数の料理レイアウト
- `slots` : 皿・本体・断面・液体・具材などの基準位置
- `mask` : 断面マスク
- `extraLayers[]` : 複製した湯気・キラキラ等
- `overrides` : 切り抜き直して差し替えた素材
- `roleSchema` : ゲーム側で解釈しやすい役割情報

これをそのまま渡せば、ゲーム本体への取り込み用データとして扱えます。

## game_renderer_example.html

v7プロジェクトJSONを読み込み、テンプレートを選択してCanvasに描画するサンプルです。
