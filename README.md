# カニ・クリーム・コロッケ 組み合わせプレビュー＆調整ツール v5

素材を全部分けた版です。

## 追加したこと
- すべての現在素材を個別 PNG に分離
- `source/` に元の大きい素材シートを同梱
- 「素材差し替え」タブを追加
- 元画像から自由に切り抜き、既存素材を置換可能
- 差し替え素材を `asset pack JSON` として保存・読込可能
- `game_renderer_example.html` でも asset pack JSON を適用可能

## おすすめの流れ
1. `素材差し替え` タブでおかしい素材を選ぶ
2. 元画像から好きに切り抜く
3. `選択素材へ置き換え`
4. `差し替え素材を書き出し`
5. 必要ならゲーム側サンプルで同じ差し替えを確認

## 収録
- `assets/` … 分離済み PNG 素材一式
- `source/` … 元画像シート
- `renderer.js` … 共通 Canvas レンダラー
- `index.html` … 調整ツール本体
- `game_renderer_example.html` … ゲーム側サンプル
