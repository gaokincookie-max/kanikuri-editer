# カニ・クリーム・コロッケ 焼き加減エディタ v14

## 今回の追加
- 焦げ用オーバーレイ素材シート `source/コロッケ衣オーバーレイ素材シート.png` を取り込み済み
- 切り出し済みオーバーレイを `assets/overlays/` に追加
- パターン側で「焼き加減」を切り替え可能
  - 通常
  - 奇跡の火入れ
  - 香ばしい焦げ
  - 真っ黒焦げ
- 全体コロッケ / 断面コロッケそれぞれのオーバーレイ透明度を調整可能

## 使い方
1. `index.html` を開く
2. 左の「パターン設定」で液体・具材・焼き加減を選ぶ
3. 「オーバーレイ調整」で透明度や倍率を調整する
4. 設定は JSON で書き出し / 読み込みできる

## 補足
- 今回は焦げ表現の調整に集中しやすいよう、軽量なプレビュー構成にしています
- 元の素材シートも `source/` に同梱しています
