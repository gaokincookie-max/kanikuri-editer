# カニ・クリーム・コロッケ 素材調整ツール v13

## 今回の追加点
- 現在のゲーム素材シート画像を `source/current_game_sheet.png` として同梱
- 切り抜き後に **背景透過** ができるようにした
- 通常素材・完成料理素材のどちらも、素材IDを保ったまま差し替え可能
- v0.9.7ベースの現在ゲーム用素材・差し替え情報を引き継ぎ済み

## 使い方
1. `index.html` を開く
2. 「素材差し替え」タブへ
3. 左で修正したい素材IDを選択
4. 元画像から範囲選択して「切り抜き作成」
5. 背景が残る場合は「背景を透過」
6. 問題なければ「この素材IDを置き換える」
7. 最後に「差し替え素材を書き出し」で JSON を保存し、ChatGPT に送る

## 背景透過について
- 四隅の背景色を基準に自動透過します
- 帯状の背景色がある素材シート向きです
- うまく消えない/消えすぎる場合は「背景透過しきい値」を調整してください

## 焼き加減対応（差し替え方式）
- 「基本パターン」→「焼き具合」から「通常 / 奇跡の火入れ / 黒焦げ」を選択できます。
- 通常の whole.png / cutFrame.png を描画するとき、対応する仕上げ画像へ差し替えます。上から重ねません。
- 4枚の仕上げ用PNGは元の画像と同じキャンバス寸法とアルファ輪郭に合わせています。
- 元のエディタデータ・プロジェクトJSONは変更していません。ゲーム本体への反映はまだ行っていません。
