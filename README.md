# カニ・クリーム・コロッケ 料理アセット調整ツール v8

## v8 の修正
- 基準レイヤーの **左右反転 (flipX)** をテンプレート／ゲーム取り込み用JSONに保存
- 透明度 (alpha)、表示／非表示 (visible)、クリップ (clip)、重なり順 (z) も基準スロット側で保持
- 目アイコンで非表示にした状態もテンプレートへ保存
- 複製レイヤーは従来どおり semanticRole と flipX 等を保持
- v7 のテンプレートライブラリ／プロジェクトJSONも読み込み可能

## 次のアセット調整
グラサンとヘッドホンは、完成料理に「装着する」前提の形へ描き直すのがおすすめです。
まずグラサンを断面コロッケの顔面カーブに合わせ、その基準に合わせてヘッドホンを描くと配置しやすくなります。

- ヘッドホン素材を、奥側が見えにくい装着向けデザインへ差し替え
- エディター / ゲーム側サンプルの両方で新素材を使用
