# カニ・クリーム・コロッケ アセット調整ツール

`index.html` をブラウザで開くだけで動きます。GitHub Pages / Netlify Drop でも使用できます。

## できること
- 内蔵スプライトシート3枚を読み込み
- 透過領域から素材候補を自動分割
- 矩形 / 多角形 / フリーハンドで自由切り抜き
- 任意画像をアップロードして切り抜き
- 切り抜いた素材を料理プレビューへ直接登録
- レイヤーごとの位置・拡大率・回転・透明度・左右反転・重なり順調整
- 複数パターンの保存と再呼び出し
- 完成プレビューPNGの出力
- プロジェクトJSONの保存 / 復元
- ゲーム挿入用ZIP (`dish_assets.json` + `assets/*.png`) の出力

## ゲーム側へ入れるデータ
「ゲーム用ZIP」を押すと以下を出力します。

- `dish_assets.json`
- `assets/*.png`
- `README.txt`

`dish_assets.json` の `recipes` に、保存した各パターンのレイヤー配置が入ります。
レイヤーは `assetId / x / y / scale / rot / opacity / flip` を保持します。

## 推奨ワークフロー
1. 起動すると内蔵3シートを自動分割し、料理プレビュー用素材として登録します
2. 「料理プレビュー」で素材をクリックしてレイヤー追加
3. 位置・サイズ・角度・重なり順を手動調整
4. パターン名をつけて保存
5. 自動分割がおかしい素材だけ「切り抜き補助」で切り直し、素材として再登録
6. 「ゲーム用ZIP」で出力

切り抜きは副次機能です。通常は料理プレビューだけで作業できます。
