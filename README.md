# 料理プレビュー調整ツール — Standalone

この版は `index.html` 内に、初期料理プレビューで使うすべての画像をData URLとして内蔵しています。

- `index.html` だけで初期プリセットが表示できます。
- `assets/` や `sources/` をGitHubへ別途アップロードしなくても初期表示は動作します。
- 追加画像の読み込み、レイヤー調整、切り抜き補助、保存・読込機能は従来通りです。
